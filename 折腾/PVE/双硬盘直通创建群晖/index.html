双硬盘直通创建群晖

发表于2026-05-27|更新于2026-05-28|折腾PVE

既然你有两块物理盘（引导盘 + 1T 数据盘）且都已经插在了 B75 主板上，这种“物理直通”的方式是性能最强、最接近真群晖的方案。

由于 B75 主板较老，不支持完美的 IOMMU 控制器直通，我们采用 磁盘 ID 直通。

第一步：在 PVE 中找出这两块盘的 ID

打开 PVE 的 **终端 (Shell)**，输入：

Bash

你会看到一堆很长的字符串。根据容量和型号找到你的两块盘：

  1. 引导盘：通常容量较小（几 GB 或 16GB 左右）。

  2. 1T 数据盘：会有 1000G 或 931G 左右的标识。

记住这两串 ata-xxxxxx 的名字。

第二步：创建黑群晖虚拟机 (VM)

在 PVE 网页操作：

  1. 常规：名称填 DS918（或其他），记住 ID（假设是 104）。

  2. 操作系统：选“不使用任何介质”。

  3. 系统：机型选 q35，BIOS 选 **OVMF (UEFI)**（RR 引导推荐 UEFI）。但是我这情况不支持，只能选择默认才能启动。

  4. 磁盘：这里很关键！ 先不要添加任何硬盘。直接点下一步直到完成。

  5. CPU：给 2 核，类别选 host。

  6. 内存：给 2GB 或 4GB（你一共 12GB，给 2GB 比较稳）。

第三步：用命令把物理盘“绑”进去

回到 PVE 终端，执行以下两条命令（请把下方的 ID 替换为你刚才查到的真实 ID）：

1. 绑定引导盘 (挂载到 sata0)：

Bash

2. 绑定 1T 数据盘 (挂载到 sata1)：

Bash

第四步：微调配置文件（防止找不到引导盘）

这是解决你之前 “Finding for bootloader disk” 报错的绝招。

  1. 在终端输入：nano /etc/pve/qemu-server/104.conf

  2. 找到 sata0 这一行，在末尾手动加上 ,model=Synology。

    • 看起来像这样：sata0: /dev/disk/by-id/ata-xxx,model=Synology

  3. 按 Ctrl+O 保存，Ctrl+X 退出。

第五步：设置引导顺序

  1. 回到 PVE 网页界面，点击 **104 号虚拟机 -> 选项 (Options)**。

  2. 双击 **引导顺序 (Boot Order)**。

  3. **只勾选 sata0**（你的引导盘），并把它拖到第一位。

  4. 取消勾选其他的（如 net0, ide 等）。

第六步：启动与安装

  1. 点击 **开机 (Start)**。

  2. 进入控制台，你应该能看到 RR 引导的彩色菜单了，不再会有“找不到盘”的提示。

  3. 如果是第一次安装，让 RR 编译好引导后重启，当屏幕出现 http://192.168.1.xxx:5000 时，用你电脑的浏览器访问。

  4. 在群晖安装界面，它会识别到那块 1T 的机械硬盘。

  1. 虚拟机磁盘镜像 (.qcow2): /var/lib/vz/images/VMID/ 或 /dev/pve/ (LVM-Thin)。
  2. ISO 镜像: /var/lib/vz/template/iso/。
  3. 虚拟机配置: /etc/pve/qemu-server/。
  4. 备份文件: /var/lib/vz/dump/
