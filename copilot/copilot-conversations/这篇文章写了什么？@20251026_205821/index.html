3.2 被动信息搜集

被动信息搜集是指在完全不与目标系统进行直接交互的情况下，从公开渠道获取信息。这种方式隐蔽性强，是渗透测试和网络侦察中至关重要的第一步。

3.2.1 公开源情报 (OSINT)

公开源情报是从公开可用的信息中收集、分析并产生有价值情报的过程。

1. 搜索引擎

搜索引擎是OSINT中最强大、最基础的工具。

  • Google黑客语法：
    利用Google等搜索引擎的高级搜索语法，可以精准定位敏感文件、目录和信息。

    • site:example.com：将搜索范围限定在指定域名。
    • inurl:admin：搜索URL中包含”admin”的页面（如后台登录入口）。
    • intext:"密码"：搜索网页正文中包含”密码”的页面。
    • filetype:pdf：搜索指定类型的文件（如PDF、DOC、XLS等，这些文件中可能包含内部信息）。
    • intitle:"index of"：搜索开放目录列表，可能直接暴露网站文件结构。

  • 网络空间测绘引擎：
    这类引擎不同于传统搜索引擎，它们扫描并索引互联网上设备的公共信息。

    • Shodan：被誉为“物联网的搜索引擎”，可以搜索到联网的设备（如摄像头、路由器、服务器）、开放端口、运行的服务及版本 banner，甚至部分弱口令信息。
    • ZoomEye（钟馗之眼）：与Shodan类似，是知道创宇推出的网络空间搜索引擎，专注于Web组件与网络设备指纹的识别。

2. 开源代码仓库

开发人员有时会无意或将测试代码上传至公开的代码仓库，导致敏感信息泄露。

  • GitHub / Gitee（码云）：
    通过高级搜索语法，可以挖掘到大量意外泄露的敏感信息：
    • 凭证信息：搜索 password、api_key、secret、ftp、smtp 等关键词。
    • 配置文件：搜索 config.json、.env、database.yml 等文件，其中可能包含数据库连接字符串、第三方服务的API密钥。
    • 数据库信息：搜索 sa password、root password 等，可能发现数据库管理员密码。
    • 员工信息：搜索公司邮箱后缀，可能找到员工列表或内部通讯录。

3.2.2 社交媒体与员工信息

攻击者常常通过收集员工信息来构建社会工程学攻击。

1. 公开源获取员工信息工具

这些工具能自动化地从多个公开源聚合个人信息。

  • theHarvester：
    一款经典的电子邮件、子域名和员工姓名收集工具。它可以从Google、Bing、LinkedIn、Twitter等多个公开数据源进行搜集，是信息收集阶段的利器。
  • Maltego：
    一款功能强大的信息收集与关联分析工具。它以图形化方式展现信息之间的关系（例如，一个邮箱地址关联到一个个人社交账号，再关联到其发布的包含公司技术栈的帖子），能够清晰地描绘出目标组织和个人的数字足迹。

2. 社会工程学

社会工程学是利用人的心理弱点（如信任、好奇、贪婪）而非技术漏洞来获取信息、访问权限或金钱的艺术。被动信息搜集是其实施的基础。

  • 信息铺垫：通过上述方法收集到的员工姓名、职位、邮箱、社交动态、兴趣爱好等，可以用来：
    • 伪造一封来自同事或高管的钓鱼邮件。
    • 在电话冒充中获取对方的信任。
    • 猜测密码提示问题的答案。
  • 心理操纵：攻击者可能伪装成IT支持人员，利用已获取的内部信息（如员工ID、部门名称）骗取受害者的登录凭证。

补充知识：其他被动信息收集手段

  • 证书透明度日志：为了监管SSL/TLS证书的签发，CA机构会公开证书日志。通过查询这些日志（例如使用crt.sh），可以发现为目标域名签发的所有证书，从而找到未被公开的子域名。
  • DNS历史记录：通过查看域名的DNS解析历史记录，可能会发现已被遗忘但仍在运行的旧服务器或测试服务器。
  • Pastebin类网站：人们经常在这些网站上分享代码和日志，其中可能包含泄露的凭证或内部信息，可使用工具进行监控。
