逆向工程师简历写作指南

必备信息

  • 个人概况：姓名/联系方式/城市（可接受远程或出差范围）、到岗时间。
  • 技术摘要：3-5 行概述，突出逆向方向（恶意代码分析/游戏反作弊/漏洞挖掘/移动安全/协议逆向等）与年限、核心工具栈。
  • 关键词标签：IDA/Ghidra/x64dbg/WinDbg/Frida/Unpack/Hook/Kernel/PE/ELF/加壳/脱壳/补丁/静态+动态分析。

能力版块

  • 语言与平台：C/C++、Python、汇编（x86/x64/ARM/Thumb），熟悉 Windows/Linux/Android/iOS 的可执行文件格式与调用约定。
  • 调试与分析：IDA/Ghidra/Hex-Rays、x64dbg/WinDbg/LLDB、Process Monitor/Process Hacker、Frida/Objection、JEB（移动）、radare2（可选）。
  • 逆向专项：协议还原、补丁制作、反调试/反虚拟机对抗、加壳/加密/混淆还原、内核驱动分析与 Hook、堆栈/内存取证、恶意代码溯源。
  • 漏洞与利用：常见内存漏洞（UAF/越界/格式化字符串/整数溢出）、利用链构造（ROP/JOP）、沙箱绕过、浏览器/内核/移动安全经验可单列。
  • 工程与效率：脚本化流程（Python/IDA/Frida 插件）、符号/日志对齐、自动化脱壳、内存快照对比、版本管理与文档产出习惯。

项目/经历呈现模板

每条经历 3-6 行，采用 “任务-行动-结果”：

  • 背景与目标：产品/样本类型、平台、逆向目的（对抗、加固评估、协议还原、漏洞验证等）。
  • 核心动作：工具和方法（如 “IDA+WinDbg 结合硬件断点定位反调试”，“Frida/Unicorn 搭建动态仿真”）。
  • 结果指标：量化产出（还原协议 XX 条、定位漏洞 N 个、脱壳耗时从 Xh 降到 Ym、命中率/检测率提升 N%、上线规则/补丁数量）。
  • 难点与对抗：列出反调试/混淆/虚拟化/自修改代码的突破点，体现深度。

可加分内容

  • 开源与作品：插件/脚本（IDA/Frida/r2）、博客/分析报告链接、CTF 逆向/RE 专项奖项、技术分享。
  • 证书与竞赛：OSCP/OSWE/OSEE、GMON、国内攻防/CTF 名次；如无证书可省略。
  • 领域经验：游戏反作弊、广告/风控对抗、桌面/移动病毒分析、IOT/车机固件逆向等请单独小节。

排版建议

  • 单页优先（1-2 页）；按 “概述 → 技能 → 经历 → 项目 → 教育/证书 → 附件链接” 排列。
  • 用清晰的小标题与项目符号，少用大段文字；突出结果数字和对抗难点。
  • 避免泄露敏感代码或受 NDA 约束细节，可用泛化描述+量化指标。

示例片段（可套用）

  • 概述：5 年逆向经验，侧重 Windows 恶意代码与协议还原，熟练 IDA/Ghidra + WinDbg/x64dbg，具备加壳对抗与自动化脱壳脚本经验，年度交付分析报告 60+。
  • 经历：负责 XX 产品反作弊，利用 IDA+硬件断点识别反调试链，编写 Frida 脚本绕过多层混淆，定位关键校验逻辑并产出补丁，作弊检测命中率提升 18%。
  • 项目：搭建自动化脱壳与符号修复流水线（Python + IDA API），批量处理样本 500+，平均分析耗时由 2h 降至 25m。

递交前检查清单

  • 关键词匹配 JD：工具、平台、场景（恶意分析/反作弊/移动/固件/浏览器/内核）。
  • 指标可量化：漏洞数量、覆盖范围、时间/效率提升、命中率/误报率变化。
  • 链接可点击：作品库、博客、报告；确认匿名或脱敏。
  • 排版干净：统一字体大小、行距；英文术语大小写统一；联系方式醒目。
