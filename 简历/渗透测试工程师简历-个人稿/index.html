渗透测试工程师简历（基于现有笔记）

请按真实情况填入姓名 / 联系方式 / 城市 / 到岗时间，并对项目细节/数据做真实补充。

概述

  • 方向：渗透测试与红队实操，侧重信息收集、弱口令/爆破、漏洞验证与提权、自动化批量刷洞。
  • 经验来源：自建笔记与靶场实战（HackMyVM/OSCP 风格、VulnHub、暗月/红日等），CTF 逆向/PWN 辅助。

技能与工具

  • 技术：渗透全流程（资产/子域/端口/目录、CMS 识别、漏洞扫描、弱口令爆破、Web/系统提权、后渗透持久化）、常见中间件/框架漏洞验证，Windows/Linux 提权路径（SUID/库劫持/配置错误/溢出绕 ASLR）。
  • 工具：nmap、gobuster/dirbuster、Sublist3r/ksudomain/InsightScan/ARL、hydra/medusa/cheetah、searchsploit、fofa_view+rad+xray、goby、Cobalt Strike、Metasploit、mimikatz、john/unshadow、proxifier、pwntools。
  • 体系化笔记：信息收集（CDN 旁站、主机发现、子域/WHOIS、目录/敏感信息、移动端）、穷举与弱口令（协议端口、验证码识别爆破）、后渗透 TIPS（hashdump、kiwi/mimikatz、RDP 启用、键盘记录）。

项目与实操

  • 靶场实战（HackMyVM/OSCP + VulnHub/暗月/红日 + 域场景）

    • 技术栈：全端口扫描/指纹枚举 + 目录/子域扫描，searchsploit/POC 验证；Web 利用（上传/LFI/SQLi/RCE）、弱口令/爆破；Linux SUID/库劫持/cron/配置错配提权，Windows 域场景下票据滥用、权限提升、横向移动。
    • 动作（项目描述）：
      • 单机 boot2root：nmap 全端口 + 指纹、目录/子域扫描 → searchsploit/POC 验证 → Web 利用（上传/LFI/SQLi/RCE）、弱口令爆破 → Linux 提权（SUID/库劫持/cron/配置错配）。
      • 域/内网题：收集凭证与票据，滥用域权限，横向移动拿下域控/高权节点。
      • 代表性链路：ApPHP MicroBlog RCE→缓冲区溢出（gdb 调试）、phtml 上传、LFI、passwd/写入提权、sudo -l 滥用、Hydra 爆破。
    • 结果：多台靶机拿到 root/域管，沉淀提权/横移操作手册和利用链，形成常见提权/横移备忘（SUID、Cron、弱口令、配置劫持、脚本提权）。

  • 批量刷洞与自动化

    • 流程：fofa_view 资产 → rad 爬虫 → xray 代理扫描（自定义 POC），或 goby 红队版批量导入 POC。
    • 结果：形成可复用的“一键资产 + 被动/主动扫描”流水线，适合外网快速摸排。

  • 脱壳与逆向/PWN 辅助（CTF）

    • 价值：用于样本分析/漏洞复现的逆向能力（UPX/MEW/exPressor/FSG/WinUpacx 脱壳，IAT 修复；栈溢出/Canary/PIE 绕过、pwntools 利用）。
    • 结果：可在拿到可疑样本或自编组件时快速静态/动态分析。

  • 护网与重保值守

    • 国家级护网行动：蓝队初级成员，负责资产梳理、风险排查、入侵检测与溯源分析。
    • 天津银行重保：系统安全值守，流量审计、日志分析、横向渗透排查与应急响应。
    • 天津市护网攻防演练：为中信天津金融科技服务有限公司制定防护策略与应急处置演练，模拟攻击应对。

  • 政务平台攻防与 CNVD 提交

    • 市级政务平台攻防（天津市大数据管理中心、天津市医疗保障局）：红队攻击方，渗透与漏洞利用验证防护能力，输出风险评估与加固建议。
    • CNVD 归档漏洞：
      • CNVD-2025-08766：天津市城市建设档案馆系统 SQL 注入，敏感数据库泄露风险。
      • CNVD-2025-08843：天津市肿瘤医院网站任意文件读取，可读取配置与敏感日志。
      • CNVD-2024-36245：天津市劳动经济学校系统信息泄露，超 1000 条学生隐私数据暴露。
      • CNVD-C-2024-16669：绍兴平正评估系统 SQL 注入，可构造 Payload 获取后台数据。
    • 技术栈与方法：Burp Suite 抓包/调试，SQLmap 自动化注入识别，dirsearch/OneForAll/FOFA 资产探测，手工路径穿越/LFI 验证，按 CNVD 模板撰写漏洞分析报告。
    • 结果：所有提交均通过 CNVD 审核公开，沉淀了信息收集、POC 构造、逻辑绕过、数据审计的实战经验，并熟悉国家级漏洞平台提交流程。

  • 网络架构与内网穿透（PVE 私有云，负责人，2024.07-2024.08）

    • 技术：PVE 虚拟化、OpenWrt/iStoreOS 旁路网关、Docker、DDNS、WireGuard/Tailscale、Nginx 反代。
    • 动作：设计隔离的虚拟化网络，云端 WireGuard 组网实现异地 VLAN 共享；Nginx 反代暴露本地站点/NAS/NVR；部署“流影”流量回溯平台+DPI，对内网异常连接实时告警。
    • 价值：熟悉隧道/反代的安全暴露、访问控制与流量监测，可将私有化服务安全上线并持续审计。

个人技能速记（渗透向）

  • 技术：资产测绘与信息收集、弱口令/爆破、Web 漏洞验证、系统提权、后渗透维持/取证、PWN/逆向辅助。
  • 工具：nmap、gobuster/dirbuster、Sublist3r/ksudomain/ARL、hydra/medusa、searchsploit、rad+xray/goby、CS/MSF、mimikatz、john、proxifier。
  • 兴趣：自动化刷洞、靶场复现与提权技巧沉淀、红队链路编排。
