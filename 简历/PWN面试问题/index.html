那有没有pwn的面试题总结？

有的，而且 PWN 面试其实非常有套路。很多安全公司问的题目都集中在 栈 / 堆 / libc / 利用思路这几块。我给你整理一份 《PWN 面试高频 40 题 + 简洁回答思路》，基本覆盖面试常问内容。

我知道你平时也用 pwntools 做题，所以很多回答我按 CTF + 面试视角来讲。

一、PWN基础（10题）

1 什么是缓冲区溢出

面试回答：

缓冲区溢出是由于程序没有对输入长度进行检查，导致数据覆盖相邻内存区域，从而改变程序执行流程。

2 栈溢出原理

结构：

buffer
saved ebp
return address

回答：

当输入数据超过 buffer 长度时会覆盖返回地址，从而控制程序执行流程。

3 什么是 shellcode

回答：

shellcode 是一段用于获取 shell 或执行恶意操作的机器代码，通常在漏洞利用中注入执行。

4 什么是 ret2libc

回答：

ret2libc 是通过覆盖返回地址调用 libc 中已有函数，比如 system(“/bin/sh”) 来获取 shell。

5 什么是 ROP

ROP = Return Oriented Programming

回答：

ROP 是通过组合程序中已有指令片段（gadget）构造攻击链，从而绕过 NX 等保护。

6 什么是 gadget

回答：

gadget 是以 ret 结尾的一段指令序列，可以用于构造 ROP 链。

7 什么是 NX

NX = No Execute

回答：

NX 是一种内存保护机制，禁止栈或堆执行代码，从而防止 shellcode 执行。

8 什么是 ASLR

ASLR = Address Space Layout Randomization

回答：

ASLR 会随机化程序内存地址，从而增加攻击难度。

9 什么是 PIE

PIE = Position Independent Executable

回答：

PIE 会随机化程序代码段地址，使得程序基地址每次运行都不同。

10 什么是 Canary

回答：

Canary 是一种栈保护机制，在返回地址前放置随机值，如果被覆盖程序会终止。

二、栈漏洞利用（10题）

11 如何绕过 Canary

回答：

常见方式：

  • 信息泄露

  • 格式化字符串漏洞

12 什么是 ret2text

回答：

ret2text 是利用程序中已有函数实现攻击，比如直接跳转到 system 函数。

13 什么是 ret2plt

回答：

ret2plt 是利用 PLT 表调用外部函数的一种利用方式。

14 什么是 ret2csu

回答：

利用 __libc_csu_init 中的 gadget 构造函数调用。

15 什么是栈迁移

回答：

栈迁移是将栈指针修改到攻击者可控内存区域，以构造更长的 ROP 链。

16 什么是 one_gadget

回答：

one_gadget 是 libc 中可以直接获取 shell 的指令位置。

17 什么是 SROP

SROP = Sigreturn Oriented Programming

回答：

利用 sigreturn 系统调用构造寄存器状态实现攻击。

18 什么是 syscall

回答：

syscall 是用户态进入内核执行系统调用的指令。

19 如何构造 execve(“/bin/sh”)

回答：

需要控制：

RAX = 59
RDI = “/bin/sh”
RSI = 0
RDX = 0

20 什么是栈帧

回答：

栈帧是函数调用时在栈上分配的一段内存，用于保存参数和返回地址。

三、堆漏洞（10题）

21 什么是堆

回答：

堆是程序运行时动态分配内存的区域。

22 常见堆漏洞

回答：

  • double free

  • use after free

  • heap overflow

23 什么是 UAF

Use After Free

回答：

在释放内存后继续使用该指针。

24 什么是 double free

回答：

同一块内存被释放两次。

25 什么是 fastbin attack

回答：

利用 fastbin 链表伪造 chunk 实现任意写。

26 什么是 unsorted bin attack

回答：

利用 unsorted bin 泄露 libc 地址。

27 什么是 tcache

回答：

tcache 是 glibc 新增的线程缓存机制，用于提高 malloc 性能。

28 什么是 tcache poisoning

回答：

通过伪造 tcache 链表实现任意地址分配。

29 什么是 chunk

回答：

chunk 是 glibc 堆分配的基本单位。

30 chunk结构

prev_size
size
fd
bk

四、信息泄露（5题）

31 为什么需要信息泄露

回答：

用于绕过 ASLR 获取真实地址。

32 常见泄露方式

回答：

  • printf

  • GOT

  • heap pointer

33 什么是 GOT

GOT = Global Offset Table

回答：

GOT 存储动态链接函数地址。

34 什么是 PLT

PLT = Procedure Linkage Table

回答：

PLT 用于延迟绑定外部函数。

35 延迟绑定原理

回答：

第一次调用函数时通过 PLT 查找 GOT 并解析真实地址。

五、PWN利用工具（5题）

36 常用 PWN 工具

回答：

  • pwntools

  • GDB

  • ROPgadget

37 什么是 pwntools

回答：

pwntools 是 Python 编写的漏洞利用框架，用于快速编写 exploit。

38 GDB 常用命令

回答：

b
run
x
info registers

39 什么是 core dump

回答：

程序崩溃时生成的内存快照。

40 PWN 利用流程

回答：

面试最好这样说：

一般流程是先分析程序保护机制，然后寻找漏洞，通过信息泄露获取地址，再构造 ROP 链或堆利用最终获取 shell。

💡 给你一个 PWN 面试非常加分的回答模板：

如果面试官问：

你做 PWN 一般怎么分析题？

你可以这样回答：

我一般会先查看程序保护机制，比如 NX、PIE、Canary、RELRO 等，然后通过静态分析和调试寻找漏洞点。如果存在信息泄露漏洞，会先获取 libc 地址，再构造 ROP 或堆利用链最终完成攻击。
