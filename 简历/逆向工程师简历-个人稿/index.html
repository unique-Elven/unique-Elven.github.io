逆向工程师简历（基于现有笔记）

请按真实情况填入姓名 / 联系方式 / 城市 / 到岗时间，再做删改。

概述

  • 方向：Windows 平台逆向与调试，课程/练习型经验（滴水逆向破解实战班第一、二期）。
  • 核心技能：x86/x64 汇编阅读，IDA/OllyDbg/x64dbg 静态+动态分析，补丁与脱壳基础，DLL 注入与 JIT 调试配置。
  • 语言/工具：C/C++、易语言、Visual Studio，IDA 6.8/7.x、OllyDbg(StrongOD)、x64dbg、CFF Explorer、dumpbin/depends。

技能要点

  • 逆向分析：熟悉注册机/校验流程定位（字符串搜索、交叉引用、条件/内存断点），JCC/JMP 补丁，ASLR/TLS 回调定位与对抗。
  • 动态调试：掌握 OllyDbg/x64dbg 的条件/硬件/内存断点、栈平衡检查，JIT 调试配置（AeDebug），多线程断点处理。
  • 注入与对抗：使用 VirtualAlloc/VirtualAllocEx+WriteProcessMemory 远程线程注入 DLL；对常见反调试（定时器、VMProtect、反虚拟机）有课堂实操。
  • 工具脚本：能为 IDA 修复 JMPOUT、sp-analysis failed 等伪控制流；了解 FLIRT 签名生成流程（pcf/sigmake）并在 IDA/OD 侧加载 MAP/SIG。
  • 插件入门：完成 x64dbg/OllyDbg 插件编写练习（菜单项、记录 JCC 指令、事件回调导出）。
  • 语言基础：C/C++ 与汇编调用约定理解；易语言用于小工具/界面（枚举进程/模块、注入器）。

项目与练习（课程/自研）

  • Windows 注册校验逆向与补丁

    • 工具：IDA、OllyDbg、StrongOD、CFF Explorer
    • 动作：通过字符串/交叉引用锁定 MessageBox 校验点，设置条件断点快速命中关键 JCC，手工修改跳转并在 IDA 生成补丁；调整 DLLCharacteristics 关闭 ASLR 便于定位。
    • 结果：生成可运行补丁文件，完成校验绕过流程文档。

  • DLL 注入与 JIT 调试实践

    • 工具：易语言、WriteProcessMemory/VirtualAllocEx/RemoteThread、OD JIT 设置
    • 动作：编写进程枚举+模块查看 UI，支持选择目标进程注入 DLL；配置 AeDebug 让 OD 接管异常，验证注入后模块可被调试与导出调用。
    • 结果：可稳定注入/卸载测试 DLL，掌握 JIT 调试路径。

  • IDA 伪控制流修复与签名制作

    • 工具：IDA 6.8/7.x、flair 工具链（pcf/sigmake）、dumpbin/depends
    • 动作：修复 JMPOUT、FakeRetValue、sp-analysis failed 等问题，手工合并函数；为 VS/易语言库生成 SIG/MAP 并在 IDA/OD 侧加载，补全函数名。
    • 结果：提升反编译可读性，减少误判的栈/返回值。

  • PWN 课程练习（Linux 32/64 位）

    • 范围：栈溢出基础、Canary/NX/PIE 对抗、远程调试、格式化字符串、stack migration、ret2text/ret2libc/ret2syscall、手写 shellcode、pwntools 入门。
    • 动作：完成多节实验（远程 PWN、IDA 远程调试、libc 版本切换、页对齐绕过 PIE、栈迁移等），整理实验笔记与利用链。
    • 结果：能复现典型栈溢出利用流程，并根据保护策略调整利用思路。

  • CTF 逆向/CrackMe 练习

    • BUUCTF 逆向题：完成 easyre/level1/xor/login/UPX 脱壳（level2）、Maze、Cr0ssfu、rome 等题目，输出 docx 版 WP。
    • CrackMe：完成 abexcm5 write-up（NEW Crack ME NOTE），用 OD/IDA/补丁流程记录关键跳转与校验逻辑。
    • 结果：熟悉 CTF 逆向题的字符串/流程定位、脱壳补丁与脚本化求解步骤。

  • 脱壳实战（ketu.md 系列）

    • 场景：手工脱壳与 IAT 修复，涵盖 UPX、MEW、exPressor、FSG、WinUpacx 等压缩/加壳样本。
    • 动作：PEiD/Exeinfo 初探，OD 结合栈平衡/硬件断点定位 OEP，插件 dump；LordPE 清理节表与修复 BaseOfCode，ImportREC 自动搜索并修正 IAT（裁剪非法 thunks、调整 RVA/Size）；根据保护情况选择是否重建导入表。
    • 结果：可从常见壳中定位 OEP 并修复可执行文件至可调试/可运行状态，为后续静态分析提供干净样本。

  • x64dbg/OllyDbg 插件练习

    • 工具：x64dbg/OllyDbg SDK、Visual Studio、C/C++
    • 动作：实现插件导出 ODBG_Plugindata/Plugininit/Menu/Action，添加主菜单项，记录/暂停 JCC 指令；练习调用 x64dbg API 做简单静态/动态信息收集。
    • 结果：具备定制调试器插件的入门能力，可扩展常用调试动作。

学习经历

  • 滴水逆向破解实战班（第一期、第二期）—— 完成课程笔记与实操（注册机破解、脱壳对抗、DLL 注入、插件开发、VMProtect 示例恢复）。

个人技能速记

  • 技术：Windows 逆向调试（x86/x64）、补丁/脱壳与 IAT 修复、CTF 逆向与 PWN 栈溢出利用、协议/校验逻辑还原、插件二次开发入门。
  • 工具：IDA 6.8/7.x、OllyDbg/StrongOD、x64dbg、LordPE、ImportREC、PEiD/Exeinfo、CFF Explorer、VS、Python/pwntools。
  • 兴趣：逆向对抗与壳分析、CTF 逆向/PWN、自动化脚本化调试、插件/小工具开发。

期望与补充

  • 期望岗位：逆向工程师/安全研究实习或初级岗位，Windows 桌面方向优先。
  • 可提供的材料：课程笔记摘要、示例补丁/注入器源码（自研练习）。
  • 待补充：真实项目/漏洞案例可按岗位要求补充；若无公开成果，建议附上代码仓库或实验报告。
