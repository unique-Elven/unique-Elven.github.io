项目改名

发表于2026-05-28|更新于2026-05-28|毕业设计开源推送
|浏览量:

改名分为两个部分：GitHub 远程仓库改名和本地文件夹改名。为了保证后续开发顺畅，建议按以下步骤操作：

第一步：在 GitHub 网页端改名

  1. 进入你的 GitHub 仓库页面 [https://github.com/unique-Elven/XSAN](https://github.com/unique-Elven/XSAN)。

  2. 点击上方的 Settings（设置）选项卡。

  3. 在 Repository name 输入框中，将 XSAN 修改为正确的名字（例如 XSCAN）。

  4. 点击旁边的 Rename 按钮确认。

第二步：同步本地的远程链接（关键）

改名后，原有的远程仓库地址失效了，你需要告诉本地 Git 新的地址。

在你的终端（XSAN_GOGUI 目录下）执行：

Bash

验证是否成功： 执行 git remote -v，如果显示的地址已经是新名字，说明同步成功。

第三步：修改本地文件夹名字（可选）

如果你想让本地的文件夹名字（XSAN_GOGUI）也和项目名一致：

  1. 关闭所有编辑器（如 VS Code, Cursor, GoLand），否则会因为文件占用无法改名。

  2. 在资源管理器中直接右键重命名文件夹，或者在上一级目录用命令行修改：

    Bash

  3. 重命名后，重新进入该目录即可。

第四步：检查代码内部引用

由于你的项目是 XSCAN，可能在以下地方还残留着旧名字 XSAN：

  • go.mod 文件里的模块路径。

  • wails.json 里的项目名称。

  • 前端 package.json 里的 name 字段。

  • README 中的标题。

建议： 在编辑器里全局搜索一次 XSAN，根据需要统一替换为 XSCAN，以免在编译或导入包时报错。
