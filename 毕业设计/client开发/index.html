第一步：本地环境准备清单 (Windows 环境)

在开始发指令给 Cursor 之前，请确保你电脑上装好了这“四大件”：

  1. **Go 语言环境 (1.20+)**：后端核心。

  2. **Node.js (18+)**：前端 Vue 的构建工具（用来打包你的界面）。

  3. C/C++ 编译器 (GCC)：这是极其容易踩坑的一点！ 虽然我们不用 C 写业务代码，但 Wails 底层绑定 Windows 的 WebView2 需要用到 CGO。

    • 建议下载安装 MSYS2 或 TDM-GCC，并把 gcc 加到系统环境变量的 Path 中。在终端输入 gcc -v 能看到输出即可。

  4. Wails CLI 工具：在终端运行下面这行命令安装 Wails 开发框架：

    Bash

第二步：重组你的目录结构 (极其重要)

不要直接在现有的 /go_server 和 /web_ui 文件夹里硬改！Wails 有自己严格的工程结构。 请在你的代码根目录下，打开终端，运行这个命令：

Bash

这会生成一个标准的 Wails 项目 xscan_client，它的结构非常优雅：

  • main.go / app.go (Go 后端的入口)

  • frontend/ (前端代码全都在这，这里就是你放 Vue 文件的地方)

  • build/ (打包用的图标和配置)

你的迁移策略应该是：把旧的 Python 逻辑翻译到 app.go 里，把 Figma 的 .tsx 翻译成 .vue 并扔进 frontend/src/ 里。
