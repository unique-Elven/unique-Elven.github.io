    5. 程序复现

    注册码的检验是：

    1. 18个字符串中取出前14个字符依次分别与”A~N”进行异或运算

    2. 将每次异或出来的结果累加保存

    3. 最后累加的结果和0x123456再次进行异或

    4. 最后异或的结果和最后面四个字符比较。

      注册机的生成思路是：

      1. 随便输入14个字符串，然后分别依次和“A~N”的结果进行异或

      2. 每次异或的结果累加保存起来，最后和0x123456异或

      3. 然后将最后异或出的结果拼接到14个字符后面，即可完成生成。
