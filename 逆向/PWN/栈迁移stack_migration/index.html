因此，在这道题目中，我们可以现在 name 上布置 rop 链，同时利用栈溢出修改 rbp 和 ret_addr 。修改 rbp 为 name 地址，修改 ret_addr 为 leave ; ret 指令

由于只能写0x18个字节，所以只能覆盖到rbp和ret_addr

 

 

注意在 system 函数执行时候，会大量消耗栈资源（形象的来说就是调用system函数申请堆栈空间的时候需要让rsp上升很多，也就是申请很多的堆栈空间），所以我们要控制好迁移后的栈地址，让 system 函数能过正常地执行。

p64(ret)*0x101是因为system占用大量资源，这样可以为缓冲区申请大量的资源，而且还要平衡堆栈。还有这个数据如果太小就会发生RSP是白色的错误，这就是没有可写权限会发生

 

而且RSP特别的小，这就是应为RSP往上移了很多，RSP上移动减小。所以我们可以填充很多个的ret来申请足够多的栈空间

 

像这样就是栈对其错误，所以再加1个ret,让栈对其就可以了

p64(name + 0xa00 - 8)是因为栈迁移方法的第一个栈地址里面的数据会被pop给ebp所以没有什么用，所以应该-8就是留着“/bin/sh\x00”等下弹给ebp（本来我还想能否直接ljust补充“/bin/sh\x00”的,但是搜了才知道ljust只能填一个字节一次，所以不行），让它pop的是/x00，这样后面才会就会正常的执行pop rdi ; ret。应为这条指令存在的位置是name+0xa00

SROP

题目;

// gcc srop.c -o srop -fno-stack-protector -no-pie -masm=intel

srop 实质是一个系统调用，这个系统调用是从栈上取值，恢复寄存器状态的一个系统调用，其系统调用号为 0xf ，rt_sigreturn

原理图：

 

 

如果是这样，那么我们是不是能够控制 rax = 0x3b ，rdi -> binsh ，rsi -> rdx -> 0 ，rip -> syscall ，就可以执行 execev(‘/bin/sh’, 0, 0) 系统调用了。

为了达到这样的攻击目标，我们首先要先能控制 rax = 0xf ，并且能够执行 syscall 指令，这样才能调用 rt_sigreturn

 

 

题目里面，可以发现 pop rax; syscall ; 这样的指令，就可以控制 rax ，并且执行 syscall 指令了。

接下来，就是 binsh ，那么要如何找到呢 ？

 

一般libc地址是0x7f，栈地址是0x7ff。

通过第二个 write 泄露内存信息漏洞，我们可以泄露出栈地址，而栈空间是我们能够写入数据的，那么我们便可以写入 /bin/sh ,最后通过 调试 + 计算得出 /bin/sh 的地址

但我们能够得到 /bin/sh 地址之后，就是我们的 srop 漏洞利用了

BROP（没有二进制程序，只有一个程序服务）

brop 一种没有二进制程序，只有一个程序服务的情况下，该程序存在栈溢出，可以通过栈溢出和程序特性进行 ROP 攻击并且提权的攻击方法。

利用前提：

  1. 存在栈溢出漏洞

  2. 没有开启 canary 或者 开启 pie

  3. 即使开启了 canary 或者 开启了 pie。但是 canary 和 pie 不变，这样就能够爆破得到 canary 和 pie。(多线程)

PS : 也有可能是溢出长度不够，那么这样就可以增加溢出长度测试， < 0x1000

回头看这道题目，明显这道题目没有 canary ，默认没有开启 pie，很难去控制 pie 是不变。除非是一个多线程的，比如程序因为栈溢出崩溃了但是，还是在继续进行，此时pie和canary就是不变的

如果是多线程题目，那么也是很容易去通过溢出判断的，即程序 crash （崩溃）后，还能继续重启，继续让你输入。

ELF 程序特性之一 ： 固定存在的 pop6_ret 及其意义

可以发现，平时所使用的 pop rdi ; ret 和 pop rsi; pop r15 ; ret ，都是从 pop6_ret 截取出来的（看硬编码）

程序IDA进去看确是这样的

 

所以可以知道下面这有些都是上面得截取拼接出来的

 

而 pop6_ret 是 __libc_csu_init 函数里所固有的，就是上面白色的IDA截图里的。

PS : ret2csu 的一个好处，就是能够控制 rdx 。

gcc - 11 之后的版本，取消了 pop6_ret 这个指令。这也是编译时候的一个安全保护

因为不能保证爆出的一定是 pop_rdi_ret

爆破函数代码

还有一种，即 pop6_ret 是 main 函数地址时候

这个时候，如果再次发送如下的 payload

如果 pop6_ret 是 main_addr ，那么又会重新回到 main 函数，即程序又有输出

如果 pop6_ret 是 pop6_ret ，那么程序就回不到 main 函数了

根据这两者的差异，就可以判断 pop6_ret 是不是一个 main 函数（也能够确认 main 函数地址）

 

 

可以找到 pop6_ret 为 0x40075a ，pop rdi ; ret 的地址就是 0x40075a + 9 ，ret 的地址就是 0x40075a + 0xa，这个加上的便宜是固定的记住就好
